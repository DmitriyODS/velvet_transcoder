# Лабораторные работы по вейвлетам (labs.pdf)

| Папка | Тема | Файлы |
|---|---|---|
| `lab1_sympy` | 1. Символьные вычисления, SymPy | task1–task4 |
| `lab2_numpy` | 2. Матрицы, NumPy, БПФ | task1, task2 |
| `lab3_pywavelets` | 3. Вейвлеты, непрерывное преобразование | task1, task2 |
| `lab4_dwt` | 4. Дискретное вейвлет-преобразование | task1, task2 |
| `lab5_images` | 5. Вейвлеты и изображения (сжатие, шум) | task1, task2 |
| `lab6_packets` | 6. Вейвлет-пакеты | task1 |
| `lab7_packets_images` | 7. Вейвлет-пакеты и изображения | task1, task2 |

В начале каждой программы объясняется её математика, по ходу кода
комментарии поясняют шаги, в конце идёт блок «Как понимать результат».
Графики открываются в окнах и сохраняются в `results/` рядом со скриптом.

## Запуск

```bash
cd lab4_dwt
../.venv/bin/python task1.py
```

Если окружение нужно создать заново:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Параметры:
- `lab2_numpy/task2.py [вариант]`: без аргумента выполняются все 6 вариантов f(t).
- `lab3_pywavelets/task2.py [вариант] [вейвлет]`: вейвлет по умолчанию `morl`
  (выбирает преподаватель), например `task2.py 2 mexh`.

Чтобы графики только сохранялись, без окон: `MPLBACKEND=Agg ../.venv/bin/python task1.py`.
